# 决策笔记（Agent Notes）

> `docs/` 与 `pages/` 写**是什么**（现状、契约、用法）；`.agents/notes/` 写**为什么**（当时的取舍与代价）。
> 本目录入库（git tracked），因此只写可公开的事实：不写设备序列号、密钥、trace 正文、截图。
> 编码前读根 `AGENTS.md`；写笔记前读本文件。

## 一篇笔记长什么样

文件名 `YYYY-MM-DD-slug.md`（日期 = 写下那天，slug 用小写英文连字符）。正文四格固定顺序，一节都不能少：

```markdown
# Agent Note: 标题（一句话说清决定了什么）

Status: <proposed | implemented | rejected | archived>

## Problem
什么处境逼出一个决定：约束、失败现场、被反复踩到的坑。只写事实，不写感想。

## Decision
决定了什么，边界在哪（做什么、明确不做什么）。理由若属事后重建，末尾加一句：
（理由为回溯性重建）

## Alternatives considered
每个被否方案写两条：
- **最强的理由**：支持它的最佳论据；写不出来说明当时没真的考虑过它。
- **为何被否**：哪条约束、证据或实测推翻了它——不是「感觉不好」。

## Consequences
- **收益**：这个决定换来了什么。
- **代价**：放弃了什么、以后要付出什么、哪里仍然脆弱。
```

## 状态就是文件夹

| 文件夹 | 含义 |
|---|---|
| `proposed/` | 已写下、尚未落地（正文 `Status: proposed`） |
| `implemented/` | 已随代码落地（正文 `Status: implemented`） |
| `rejected/` | 考虑过并明确否决（正文 `Status: rejected`） |
| `archived/` | 已被新决定取代，仅存历史（正文 `Status: archived`） |

- **严禁全局 INDEX.md**：状态由所在文件夹决定，**移动文件即迁移状态**；正文 `Status:` 行必须与文件夹一致。
- 迁移用 `git mv`：`proposed/` → `implemented/` 或 `rejected/`；被取代后 → `archived/`。
- `archived/` 永久冻结：**只允许追加**一段迁移说明（取代它的新笔记链接 + 日期），**不许改结论**。

## 什么时候必须写

非平凡改动命中以下任一类即写：

1. **用户可见行为**：CLI 参数、回执文案、控制台交互、终局语义。
2. **架构切分 / 调用方向**：谁调谁、谁拥有状态、进程边界。
3. **跨文件契约**：P0 表条目、事件 topic、工具 schema、固定 schema 落盘。
4. **流程与工具链 / 环境变量**：新增或改变 env、构建 / 诊断 / 发布流程。
5. **测试策略**：测什么、以什么为准（真机 vs 合成）、什么不再测。
6. **落盘 / 网络 / 配置格式**：文件格式、存储布局、网关协议。

纯机械改动不写：样式与格式化、注释错字、不改行为的依赖补丁、纯重命名。

时序：**笔记与代码同批提交**（同一 commit 或紧邻的 commit）。允许事后补写，日期写补写那天，事后重建的
理由必须标注。**不溯及历史**：制度建立（2026-09-15）之前的批次不补写笔记——那些批次的取舍与代价以制度
建立后的笔记为准。

## 隐私红线

笔记入库，等于发布。以下内容**严禁**进笔记：

- 设备序列号、真机画面里的个人信息、trace 正文、截图与 base64；
- API key、token、认证头、内网端点；
- `memory/`、`outputs/`、`.env`、`models.json` 里的任何取值。

要举例就用合成数据（「某台测试机」「合成屏幕」）。

## 大升级规矩

推翻旧决定时：

- **不改旧笔记结论**：把旧篇移进 `archived/`，只追加迁移说明；
- **新写一篇**：写清与旧篇的**管辖边界**（新篇管什么、旧篇的哪部分仍然有效）；
- **互相引用**：新篇正文链接旧篇，旧篇的迁移说明链接新篇。

## 和其他文档的分工

| 载体 | 写什么 |
|---|---|
| 根 `AGENTS.md`（P0 表） | 不可违反的现行约束 |
| `pages/` | 用户手册：现状与用法 |
| `docs/future-roadmap.md` | 实现状态与延期项 |
| 模块 docstring | 模块契约 |
| `.agents/notes/` | 当时的取舍、被否方案与代价 |

笔记**不取代**任何上述文档：结论变了要同步 P0 表与 `pages/`，笔记只负责解释为什么。往笔记里写路径时
写真实存在的路径——`tests/docs/test_doc_references.py` 会核对 `AGENTS.md`、`README.md` 与
`docs/future-roadmap.md` 的引用，笔记自身也应遵守同一事实标准。
