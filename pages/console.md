# Web 控制台

本地 Web 控制台（NiceGUI）用于实时监看与操控，是**可选观察层**：不启动它，CLI / headless 用法的全部
机制不受影响。启动：

```bash
.venv/bin/python -m phone_agent.web --device-id <serial> --port 8080
```

默认地址是 `http://127.0.0.1:8080`。

控制台默认只监听 `127.0.0.1`；任务由独立 runner 子进程执行，页面通过 `PHONE_AGENT_RUNS_DIR` 下的
追加式文件观察，重启后可回放现有 run 并重连仍存活的任务。Web 进程不拥有设备访问、工具执行或工作流路由。

## 布局

固定顶栏（品牌、运行状态、设置、演示标识）+ 视口高度内的两栏工作台：

| 区域 | 内容 |
|---|---|
| 顶栏（52px） | 品牌与一句说明、当前运行状态 pill（含“在等什么”的提示）、设置抽屉入口；演示标识只是一个小 badge，只出现在 fake 预览页 |
| 设备栏（336px） | 当前画面按剩余视口高度等比 contain 完整显示；下方一条紧凑历史缩略条 |
| 右栏 | 紧凑 composer（多行任务、运行/停止）+ 一行运行元数据 + 次级页签工作区 |

桌面整页不滚动（重内容各自区域内滚动），最大宽度约 1440px 居中；窄屏回落为单列自然滚动。

## 右栏页签

| 页签 | 内容 |
|---|---|
| 步骤 | 顶部“当前步骤”窄条（长任务不滚动也能看到在跑哪一步）；历史每步含状态图标、意图、工具/目标芯片、端到端耗时；展开看参数、回执与模型/工具耗时拆分；有截图的步骤可一键把左侧画面钉到该步；开启模型流式增量时，上方出现轻量“模型流式输出”面板 |
| 任务板 | TaskDoc 结构化渲染：目标、路线项（状态图标 + 证据）、最近步骤流程线 |
| 应用库 | App-KB 条目表（名称/包名/来源/成功次数/有效性）；定时刷新只读 `kb.json` 快照，不构造 store、不写回；+ 手动 dream 整理 |
| 记忆 | 能力状态（生效/影子/关闭/待岗）、回想统计（评估数/Hit@1/污染率/card·rule 抑制计数）与当前回想模式、历次任务档案表 |
| 产出 | agent 写出的 HTML 文档列表（攻略/计划/报告）：沙箱预览、新窗口打开、删除（仅用户可操作，需确认） |

## 状态与真实性

运行状态只由真实事件推进，待命/结束与中间态不靠动画伪装：

| 状态 | 含义 |
|---|---|
| 等待模型调用返回 | 请求在途；界面只写“网络 / 队列 / 推理无法区分”，不把它说成网关纯推理耗时 |
| 执行工具 | 工具正在设备上执行 |
| 等待人工 | HITL 横幅出现在主要工作区顶部（不是页尾），原文显示问题，可输入或同意/拒绝 |
| 已请求停止 | 软停止请求已发出但尚未收到终局事件；不会冒充“已停止”，收到终局才转为结束态 |
| 已完成 / 未完成 / 已接管 | 终局只由 `run_end` 决定，未完成会给出原因 |

- **模型身份**：“首选模型”来自实际发出的请求绑定；“实际模型”只取 provider 返回的元数据，缺失时显示
  **未上报**，绝不用首选或配置的备用名顶替。
- **参考图**：没有提交 `screen_seq` 的帧标注“参考帧（未验证）”；多个无 seq 的帧各有独立身份，不互相覆盖，
  也不冒充新观测。
- **可选记忆**：App-KB 快照按内容（显式 `generation`/`version`，否则内容摘要）标识；run 启动时发现漂移只写
  一条 `memory_generation_drift` 审计事件（captured/actual），绝不阻止手机任务。
- **模型流式**（`PHONE_AGENT_STREAMING=on`，抽屉可覆盖）：增量显示模型正文与 SDK 上报的推理文本（Responses 的
  `summary_text`、Anthropic 的 thinking、`reasoning_content`）；没有上报就不编造。面板默认跟随最新尝试，点历史尝试芯片
  即钉住，出现“回到最新”按钮可恢复跟随；新 run 会清空并隐藏旧面板。每次尝试（首选、以及 A 包 fallback 的备用调用）有独立
  身份：失败/中断的尝试保留已收到的部分文本并标注“中断 + 原因”，备用尝试单独呈现，**绝不把备用文本拼进首选半截回复**；
  备用是否流式由备用自身的模型/全局声明决定，不会被首选角色覆盖强制打开。工具参数不完整时不会执行任何动作（工具只从
  聚合完成的消息执行）；流式不改变动作序列、安全策略、重试与 usage 计账（usage 仍按完整消息计一次）。事件只含文本字段，
  不含 base64、密钥或认证头；面板是实时视图（长文本显示末尾并标注“已接收 N 字”，完整文本以最终消息为准）。
  抽屉开关显示的是**生效值**：模型条目/`roles.actor.streaming` 覆盖开关时会明确提示，不会出现开关写 off 而实际仍在流式。
- 一行元数据收敛 run id、首选/实际模型、token、已持续与最近事件时间；不为每个字段做大卡片。

## 操控

| 操作 | 行为 |
|---|---|
| 运行 | 多行任务目标；`Ctrl / ⌘ + Enter` 运行，单独回车换行，避免多行任务误提交 |
| 停止 | 软停止：向当前 run 发送停止请求，页面提示“已请求停止（当前调用/步骤返回后收尾）”；runner 让当前步收尾，run 以 takeover 终局结束 |
| 人工中断 | `ask_user` / `take_over` / `hard` 档确认时横幅置顶，原文显示问题，输入后继续 |
| 历史钉选 | 点击缩略图钉住该帧，再点一次或点“回到最新”恢复跟随 |
| 配置抽屉 | 每轮运行的覆盖配置（设备/模型/备用模型/安全模式/预算/grounding/记忆开关/模型流式）；只对下一轮运行生效，不写回 `.env`；模型流式一项显示生效值与来源（模型/角色声明可覆盖开关）；设备 serial 留空/纯空白 = 显式自动（不继承 `.env` 的 serial） |

浏览器只接收投影后的事件，不发送 API key、认证头或完整配置。

## 本地合成预览

`scripts/fake_console_preview.py` 提供隔离的合成预览：只使用内存状态、生成的安卓风格画面与临时产物目录，
不构造真实 bridge / runner / 设备 / 模型客户端 / 记忆存储；状态切换入口藏在小 badge 的菜单里，
不占用工作台。用于本地看版式，不作为真实运行证据。

```bash
.venv/bin/python scripts/fake_console_preview.py --root /tmp/tw-console-preview --port 8091
```
